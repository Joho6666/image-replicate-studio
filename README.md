# 图片复刻 Studio

本地网页工具：照着抖音 / 小红书上的 AI 写真、韩系街拍、自拍案例，出同风格的图片，并能固定同一个模特出一整组。

流程：**抓案例 → 选 moodboard → 结构化提示词出图 → 对比原图挑图 → 固定模特换脸 → 导出拼图**。

## 功能
- **① 案例**：粘贴抖音分享链接，用 TikHub 抓图文原图（视频每 6 秒截一帧），自动识别作者文案里的 prompt；勾选最多 3 张当 moodboard。
- **② 模特**：上传照片或从出图里框出脸，作为固定模特。
- **③ 出图**：6 个验证过的场景预设（自拍、街拍、CCD、对镜等），表单实时拼成英文提示词；支持 gpt-image-2.5 / 1.5、grok；一键多场景批量出图。
- **④ 画廊**：打星、和案例原图并排对比、换脸、换后期（手机原图感 / 柔和暖调 / CCD）、导出原图和拼图（默认加「AI 生成」角标）。
- **⑤ 风格卡**：把一套满意的 moodboard + 表单 + 后期 + 高星成品存起来，所有项目一键套用。
- 连接状态灯与长连接自检、失败重试、grok 水印自动处理。

## 运行
需要 Node.js ≥ 20 和 ffmpeg，零 npm 依赖。

```bash
cp .env.example .env.local   # 填生图中转站地址/key 和 TikHub key
node server.mjs              # 打开 http://localhost:3400
```

Windows 可直接双击 `启动图片复刻.bat`。测试：`npm test`。

生图接口需要 OpenAI 兼容的 `/v1/images/generations` 和 `/v1/images/edits`（带参考图时用 edits）。

## 目录
| 路径 | 说明 |
|---|---|
| `server.mjs` | HTTP 接口和静态页面 |
| `lib/` | 中转站调用、TikHub 抓取、提示词配方、ffmpeg 后期、项目与风格卡存储 |
| `public/` | 前端（原生 HTML/JS） |
| `docs/` | 设计文档、真实感研究、优化路线 |
| `data/` | 运行时数据（项目、案例图、出图、风格卡），不进仓库 |

更详细的操作说明见 [使用说明.md](使用说明.md)。

## 注意
- 抓下来的案例图版权属于原作者，只作本地参考，不要再发布。
- 发布 AI 生成的图片时，按平台规则声明「AI 生成」。
- 用真人照片做模特或换脸，需要本人同意。
