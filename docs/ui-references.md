## 看过但不建议用
- 搜 "ai creative studio dashboard" 的结果几乎都是紫色渐变加玻璃拟态的 AI SaaS 仪表盘，同质化严重，和我们的"真人质感"定位不符，不借鉴。
- 修图 App 的深色手机界面：好看，但是手机端、深色，当前 Studio 是桌面浅色，暂不适用。
